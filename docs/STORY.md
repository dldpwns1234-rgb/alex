# 기억 조각

회귀와 환생에 이야기를 붙이는 조각 12개. 게임 수치에는 영향이 없다. 열리면 짧은 독백 카드가 뜨고, 회귀 탭 맨 아래 '기억의 서'에서 다시 읽는다.
2026-10-02: 반전(마왕 = 먼저 회귀를 거듭한 옛 용사)을 넣고 진지한 독백 말투로 썼다. 방장이 이 방향으로 확정했다.

## 정할 것

- 반전을 뺀다면 6·9·10·11을 고친다 (마왕 = 마왕군의 왕, 여신은 조력자)
- 말투를 유머 쪽으로 가져간다면 3·5·8에 가벼운 한 줄씩을 더한다
- 조각마다 작은 보상(업적처럼)을 줄지. 지금은 이야기만이다
