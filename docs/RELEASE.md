## 2. itch.io에 올리기 (계정 주인이 직접)

1. GitHub 저장소의 Actions에서 최근 "Web build & deploy" 실행의 산출물(web 빌드)을 내려받거나, 익스포트 템플릿이 있는 PC에서 `godot --headless --export-release "Web" build/web/index.html`로 만든다.
2. `build/web` 안의 파일들(index.html이 맨 위에 오게)을 zip으로 묶는다.
3. itch.io → Upload new project → Kind of project: **HTML**. zip을 올리고 "This file will be played in the browser"를 켠다.
4. Embed options: 뷰포트 **720 × 1280**, "Mobile friendly" 켬, 방향 **Portrait**, "Fullscreen button" 켬. SharedArrayBuffer 옵션은 **끈다** (단일 스레드 빌드라 필요 없다).
5. 아래 문안과 스크린숏을 넣고 공개 범위를 정한다 (처음에는 Restricted로 지인 테스트를 권한다).

## 3. 페이지 문안

**제목**: 회귀 용사 키우기

**한 줄 소개**: 탭하고, 동료를 키우고, 막히면 과거로 회귀해서 마왕성 끝까지.

**소개**

> 마왕에게 쓰러진 순간, 용사는 그날 아침 마을 어귀에서 다시 눈을 뜬다.
>
> 화면을 탭해 몬스터를 베고, 골드로 전사·궁수·마법사·성직자·용기사를 고용해 함께 싸우자.
> 벽에 막히면 회귀해서 '기억의 결정'을 가져오고, 더 멀리 가면 환생해서 '운명의 실'로 운명을 바꾼다.
>
> - 탭과 자동 전투가 함께 돌아가는 클리커 인크리멘탈
> - 회귀(기억의 상점 7종)와 환생(운명의 상점 8종), 그리고 자동화
> - 단련 30종, 동료 승급, 장비 3칸과 강화·제작
> - 업적 38종, 도전 판 5종, 하루 세 번의 시련의 탑
> - 600부터 마왕성, 1000마다 마왕, 4000에 최후의 마왕
> - 회귀할 때마다 열리는 기억 조각 12개의 이야기
> - 창을 닫아도 오프라인 보상, 저장 내보내기·가져오기
>
> 세로 화면, PC와 모바일 브라우저에서 플레이할 수 있습니다.

**장르 / 태그**: Clicker, Idle, Incremental, Fantasy, Singleplayer, Korean

**스크린숏 후보** (720 × 1280): 첫 화면(탭 안내), 동료 다섯과 마왕성 전투, 회귀 탭(결정 배율과 기억의 서), 기억 조각 카드, 시련의 탑
