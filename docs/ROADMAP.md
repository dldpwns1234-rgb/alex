# 개발 로드맵 — 서리 변경 (Frostmarch)

---

## 원칙

> **"전부 얇게"가 아니라 "고리 하나씩 닫기".**

각 마일스톤이 끝날 때마다 **플레이 가능하고, 실패할 수 있는 상태**여야 한다.
"실패할 수 있다"가 핵심이다. 실패 조건이 없는 빌드는 게임이 아니라 장난감이다.

**아트는 M5까지 미룬다.** 그 전까지 모든 것은 색깔 네모다.

---

## M0 — 뼈대 (1주)

Godot 프로젝트를 세우고 §ARCHITECTURE의 분리 구조를 실제로 만든다.

- [ ] Godot 4 프로젝트 생성, `sim/` `game/` `data/` 디렉터리 구조
- [ ] `sim/world.gd` — 틱 진행만 하는 빈 시뮬레이션
- [ ] `sim/calendar.gd` — 날짜/계절/연차
- [ ] `game/main.gd` — sim을 틱시키고 날짜를 화면에 출력
- [ ] 게임 속도 조절 (일시정지 / 1x / 2x / 4x)
- [ ] GUT 도입 + 첫 테스트 (계절 전환이 30일마다 일어나는가)
- [ ] **웹 익스포트 CI** — GitHub Actions → GitHub Pages 자동 배포 ([ARCHITECTURE §12](ARCHITECTURE.md#12-플랫폼과-배포))
- [ ] 폰 브라우저에서 접속해 날짜가 흐르는 것 확인

**완료 기준:** 화면에 날짜가 흐르고, 계절이 바뀌고, 일시정지가 된다.
그리고 **푸시하면 폰에서 최신 빌드를 열어볼 수 있다.**

**함정:** 이 단계에서 구조를 대충 잡으면 나중에 전부 다시 짜야 한다. 여기가 제일 중요하다.

> **웹 배포 CI를 M0에 넣는 이유:** 나중에 붙이려면 이미 쌓인 코드가 웹에서 안 돌아가는 걸
> 뒤늦게 발견하게 된다. 처음부터 켜두면 웹 호환성이 깨지는 순간 바로 알 수 있다.
> 부수 효과로, 이동 중에 자기 게임을 만져보며 재미를 검증할 수 있다.

---

## M1 — 타일맵과 건설 (2주)

- [ ] 64×64 타일맵 + 카메라 (팬/줌)
- [ ] 지형 타일 3종: 평지 / 숲 / 바위
- [ ] 건물 배치 UI — 그리드 스냅, 배치 가능 여부 표시
- [ ] 건물 6종 정의 (`data/buildings/`): 오두막 · 농장 · 방앗간 · 화덕 · 나무꾼 오두막 · 창고
- [ ] 건설 비용 소모 + 건설 소요 일수
- [ ] 자원 보유량 HUD

**완료 기준:** 건물을 놓을 수 있고, 자원이 줄고, 며칠 뒤 완성된다.
**아직 재미없어도 된다.**

---

## M2 — 가구와 물류 (3~4주) ⚠️ 최대 난관

**이 프로젝트에서 가장 어렵고 가장 재밌는 구간이다.** 시간이 오래 걸릴 것을 각오한다.

- [ ] `sim/family.gd` — 가구 생성, 건물 배치, 식량/장작 소비
- [ ] 생산 체인 2개: `밀 → 밀가루 → 빵`, `목재 → 장작`
- [ ] `sim/logistics/` — 운반꾼 유닛, flow field 경로 탐색
- [ ] 운반 요청 큐 + 유휴 운반꾼 배정
- [ ] 화면에서 운반꾼이 실제로 걸어다니는 것이 보임
- [ ] 인구 유입 (주거 + 식량 여유 시)

**완료 기준:** 농장에서 밀이 나고, 운반꾼이 방앗간으로 옮기고, 빵이 구워져 가구가 먹는다.
그리고 **창고 위치를 잘못 잡으면 물류가 막히는 것이 눈에 보인다.**

**함정:** 여기서 완벽을 추구하면 몇 달이 사라진다. "돌아간다" 수준에서 M3으로 넘어가고, 나중에 돌아온다.

---

## M3 — 계절과 생존 (1~2주) 🎯 여기서 처음 "게임"이 된다

- [ ] 계절별 생산 배율 (겨울 −80%)
- [ ] 겨울 장작 소비 2배
- [ ] 식량/장작 부족 시 아사·동사 → 인구 감소
- [ ] 패배 판정 (인구 0)
- [ ] 승리 판정 (1년 생존)
- [ ] **`tools/headless_balance.gd`** — 헤드리스 밸런싱 하네스
- [ ] 시드 100개 돌려 "몇 %가 첫 겨울에 죽는가" 측정

**완료 기준: 첫 겨울을 넘기는 것이 실제로 어렵다.**
이 시점에 친구에게 플레이시켜 보라. 재미없으면 여기서 방향을 재검토한다 — 아트에 손대기 전에.

---

## M4 — 전투 (3~4주) ⚠️ 두 번째 난관

- [ ] `sim/combat/battle_sim.gd` — 20Hz 고정 timestep, 결정론
- [ ] 유닛 상태 머신 (탐색 → 접근 → 교전 → 후퇴)
- [ ] 병종 3종: 창병 · 검병 · 궁수
- [ ] `sim/military/soldier.gd` — 병사 개체, 이름, 퍼머데스
- [ ] 병사 = 노동 이탈 + 식량 2배 소비 (임금은 M6에서)
- [ ] **거점 방어전** — 마을 맵에서 습격 처리
- [ ] 명령 포인트 UI (3~5개, 돌격/후퇴/집중공격/방어태세)
- [ ] 방어시설: 성벽 · 문 · 방어탑
- [ ] 습격 사전 경고 (N일 전 정찰 보고)
- [ ] 전투 결정론 테스트 (동일 시드 → 동일 결과)

**완료 기준:** 겨울에 몬스터가 오고, 병사들이 자동으로 싸우고, 명령 포인트를 쓸지 말지 고민하게 된다.

**주의:** 관전이 지루하면 명령 포인트 설계를 재검토한다. 이 단계의 진짜 검증 항목이다.

---

## M5 — 아트 1차 투입 (2주)

**여기서 처음으로 도트를 찍는다.** M4까지의 재미가 확인된 뒤에.

- [ ] 타일셋 (평지/숲/바위/눈)
- [ ] 건물 스프라이트 6~10종
- [ ] 유닛 스프라이트 (주민/병사 3종/몬스터 2종) + 4방향 걷기
- [ ] 계절별 색조 변화 (겨울 눈 덮임)
- [ ] UI 스킨 1차

**완료 기준:** 스크린샷을 찍어서 남에게 보여줄 수 있다.

> **아웃소싱 검토 지점.** 도트 아트는 학습 곡선이 별개다.
> 직접 찍을지, 에셋을 살지, 외주를 줄지 여기서 판단한다.

---

## M6 — 무역과 원정 (3주)

경제 고리를 닫는 단계. **여기서 게임이 완성된 형태가 된다.**

- [ ] 몬스터 부산물 (마정석 · 가죽 · 뿔) 드랍
- [ ] `sim/trade.gd` — 교역대 파견, 왕복 소요일, 시세
- [ ] 은화 도입 + **병사 임금** (미지급 시 사기 하락/이탈)
- [ ] 겨울 교역로 폐쇄
- [ ] 교역대 호위 (미호위 시 습격 위험)
- [ ] **토벌 원정** — 세계지도의 소굴에 파견, 마을 방어 공백 발생
- [ ] 소굴 제거 시 해당 방향 습격 빈도 감소

**완료 기준:** GDD §1.3의 핵심 순환이 실제로 돌아간다.
몬스터를 잡아야 돈이 생기고, 돈이 없으면 병사가 떠난다.

---

## M7 — 육성과 장비 (2주)

- [ ] 병사 레벨/경험치 (전투 참가로 획득)
- [ ] 훈련소
- [ ] 장비 티어 4단계 (조잡한 → 철제 → 강철 → 마력 부여)
- [ ] 대장간 레벨 3단계
- [ ] **마정석 선택** — 팔 것인가, 장비에 쓸 것인가
- [ ] 장비 지급 UI

**완료 기준:** 마정석 앞에서 매번 갈등하게 된다.

---

## M8 — 연차 난이도와 마무리 (3주+)

- [ ] 연차별 습격 규모/강도 스케일링
- [ ] 승리 조건 (3년 생존 → 대요새 완성)
- [ ] 세이브/로드
- [ ] 튜토리얼 또는 첫 플레이 안내
- [ ] 사운드 · 음악
- [ ] **밸런싱** — 헤드리스 하네스 활용, 여기에 가장 많은 시간이 든다
- [ ] 플레이테스트 반복

|---|---|---|
| M0 뼈대 | 1주 | 1주 |
| M1 타일맵·건설 | 2주 | 3주 |
| M2 가구·물류 ⚠️ | 3~4주 | 7주 |
| **M3 계절·생존 🎯** | 1~2주 | **9주 — 여기서 게임이 됨** |
| M4 전투 ⚠️ | 3~4주 | 13주 |
| M5 아트 1차 | 2주 | 15주 |
| M6 무역·원정 | 3주 | 18주 |

이 추정은 낙관적이다. M2와 M4는 예상의 2배가 걸릴 수 있다.

## 중단 지점 (Kill Points)

프로젝트를 정직하게 관리하기 위한 사전 합의. **여기서 재미없으면 방향을 바꾼다.**

| 시점 | 확인할 것 | 실패 시 |
|---|---|---|
| **M2 종료** | 물류 병목을 해결하는 것이 재미있는가? | 물류를 추상화하고 경영 깊이를 다른 데서 찾는다 |
| **M3 종료** ⭐ | 첫 겨울을 넘기는 것이 긴장되는가? | **가장 중요한 검증 지점.** 여기서 재미없으면 기획 자체를 재검토 |
| **M4 종료** | 자동 전투 관전이 지루하지 않은가? | 명령 포인트 재설계, 또는 턴제 전환 검토 |
| **M6 종료** | 핵심 순환이 플레이어를 밖으로 밀어내는가? | 무역 보상 또는 임금 압박 강도 조정 |

**M3이 가장 중요하다.** 아트에 손대기 전에 재미를 검증하는 마지막 지점이다.
