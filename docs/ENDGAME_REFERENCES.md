# 4000 이후 콘텐츠 레퍼런스

최종 스테이지 4000(최후의 마왕) 뒤의 게임을 감으로 짓지 않기 위해 모은 자료. 2026-10-02 시작.
우리 상황: 4000은 float 한계(1.8e308) 때문에 둔 끝이고, 사람 정책 봇은 6시간 15분 안팎에 닿는다 (docs/BALANCE_SIM.md).
방장 결정(2026-10-02): **초월(3번째 층) → 심연(무한 도전 모드)** 순서. 큰 수 체계 전환은 정말 필요할 때로 미룬다.
앞 단계 자료는 docs/LATEGAME_REFERENCES.md.

## 2. 3번째 층: 공통 원칙과 우리 '초월' 적용안 (윤슬)

### 공통 원칙

1. **숫자 한계를 층의 문으로 쓴다.** AD는 1.8e308에 닿는 순간을 첫 층으로 만들었고, 한계를 푸는 것(Break Infinity)은 나중의 보상이다. 우리 4000도 같은 자리라, 끝이 아니라 **초월의 문**으로 다시 부르면 된다. 큰 수 체계는 "한계 돌파"라는 먼 보상으로 남긴다.
2. **위 층은 같은 길을 다른 규칙으로 다시 걷게 한다.** NGU는 같은 보스 301을 난이도만 바꿔 다시 오르게 하고, AD 천상체는 판마다 규칙을 비튼다. 스테이지를 늘리지 않고도 콘텐츠가 생긴다 (우리 숫자 한계와 잘 맞는다).
3. **위 층 화폐로 사는 것은 '아래 층을 빨리 지나가게 하는 것'과 '새 규칙'이다.** Clicker Heroes 아웃사이더(Borb·Phandoryss), Idle Slayer의 활동형/방치형 갈래. 단순 배율만 주면 지루하다 (LATEGAME_REFERENCES 1절 1번과 같은 결론).
4. **남기는 것은 '수집'과 '해금'이다.** 업적·통계·유물·해금 기록은 모든 게임이 남기고, 성장 수치(레벨·화폐)는 지운다.
5. **초월 시점을 게임이 판단하게 돕는다.** Clicker Heroes는 "역대 최고가 여러 판째 안 오를 때"가 기준이다. 우리는 4000이 고정 문이라 판단이 쉽지만, 두 번째부터는 "얼마나 빨리 다시 4000에 닿았나"가 보상의 기준이 될 수 있다.

### 우리 '초월' 적용안 (초안, 방장 확인 전)

| 항목 | 안 | 근거 |
|---|---|---|
| 문 | 최후의 마왕(4000) 처치 뒤 회귀 탭에 "초월" | 원칙 1 (AD Infinity) |
| 지우는 것 | 운명의 실·운명의 상점·환생 횟수, 기억과 회귀 기록, 판 전체, 장비와 강화석, 탑 층 | 원칙 4. 장비까지 지워야 첫 삶이 다시 '키우는' 맛이 난다 |
| 남기는 것 | 업적·통계, 기억 조각, 도전 달성 보너스, 자동화 해금, 설정 | 원칙 4. 자동화를 남겨야 두 번째 길이 노동이 아니다 (LATEGAME 1절 2번) |
| 화폐 | **별의 파편**. 첫 초월 1개 + 걸린 시간이 짧을수록 더 (예: 6시간 ÷ 이번 걸린 시간, 제곱근) | 원칙 5. 같은 4000을 다시 가는 동기가 '더 빨리'가 된다 |
| 별의 상점 | ① 빨리 지나가기: 시작 운명의 실, 시작 결정, 회귀 문턱 낮추기, 자동 환생 ② 새 규칙: 스킬 4번째 칸, 동료 각성(승급 6~10단계), 장비 4번째 칸 | 원칙 3 (아웃사이더, 시간의 돌 두 갈래) |
| 별자리 시련 | 초월할 때마다 하나씩 열리는 규칙 비튼 판 (예: 회귀 없이 4000, 동료 둘만, 스킬 쿨타임 2배). 깨면 고유 보상 | 원칙 2 (천상체, NGU 난이도별 도전) |
| 숫자 한계 | 스테이지 상한 4000과 1e300 자르기는 그대로. 체력 성장률을 올리는 '악몽 난이도'는 한계에 더 빨리 닿으므로 넣지 않는다 | 원칙 1 |
| 먼 보상 | 초월 N회 뒤 "한계 돌파"(큰 수 체계로 4000 너머)를 목표로 남긴다 | AD Break Infinity |

정할 것 (방장): 장비를 지울지, 별의 파편을 시간 기준으로 줄지, 별자리 시련의 수(첫판은 5개 안팎).
